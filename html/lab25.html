CS329Z：AI Agent 系统工程（Engineering AI Agents）

从单一的大语言模型（LLM）走向复合 AI 系统（Compound AI Systems）——将语言模型、检索器、外部工具、记忆模块、编排框架与优化器协同组合——正在重塑现代软件与人工智能应用的构建方式。

本课程围绕 系统（System）、数据（Data） 与 评测（Evals） 三大支柱展开，带你跨越从基础模型调用、固定工作流（Workflows）到自主智能体（Autonomous Agents）的完整技术光谱。你将首先从零手写核心组件（检索增强生成、工具调用协议、Agent 主循环、上下文压缩与沙箱隔离），透彻理解底层运行机制；随后掌握 DSPy、LangGraph、Temporal 等工业级抽象框架，并深入多 Agent 协作、提示与权重优化、基准构建、安全防护及软件工程 Agent 等核心课题。

先修要求与学习路径

学习本课程需要具备扎实的 Python 编程能力，熟悉常见的 HTTP/API 调用，并掌握基础的概率统计、线性代数与自然语言处理概念（如词向量、交叉熵损失、训练/验证/测试集划分及基础的 Transformer 机制，相当于修读过 CS224N、CS336 或具备同等工程背景）。你无需事先掌握任何 Agent 开发框架。

全课程按四个模块循序渐进展开：

模块覆盖讲次核心内容与能力目标
一、基础与核心组件第 01–04 讲剖析 Agent 的核心解剖结构（模型、推理、记忆、工具、环境）；深入 LLM 解码、注意力复杂度与推理系统瓶颈；掌握端到端 RAG 检索管线与 Function Calling / MCP 工具协议。
二、架构、记忆与系统优化第 05–09 讲对比手写 Harness 与 DSPy、LangGraph、Temporal 持久编排；掌握工作流与 Agent 设计模式、长上下文管理、跨会话记忆架构、多 Agent 协作机制，以及提示演化（MIPROv2、GEPA）与强化学习微调（PPO、GRPO）。
三、数据飞轮与评测工程第 10–14 讲从 Terminal-Bench 实战理解“规格即评测”；掌握轨迹、示范与反馈数据的构建与筛选；使用四元组框架（Request、Environment、Stopping Criteria、Scorer）与三类评分器（Code、LLM-as-Judge、Human）搭建高可靠评测基础设施。
四、安全防护与前沿应用第 15–19 讲防御直接与间接提示注入、构建权限模型与沙箱隔离；深入剖析 SWE-agent、Claude Code、OpenHands 等编程 Agent 架构，探索主动式 Agent（Proactive Agents）与多模态计算环境。

实战作业与项目指南

理论知识只有落地为可运行的代码与可复现的实验才能真正内化。本教程配套四项核心工程实践与一份源码导读：

  • HW1：从零搭建 Agent Harness：不依赖任何第三方 Agent 框架或原生 Function Calling 接口，使用纯 Python 从零构建企业内部助手 Cardinal Energy Agent。涵盖邮件分类、日报生成、BM25 倒排索引、多跳问答、自定义工具协议、Agent 循环、分页文档检索、终端沙箱执行、上下文压缩、跨会话记忆、用户审批与防注入护栏等 17 个递进模块。
  • HW2：构建 Agent 评测体系：针对给定 Agent 系统设计完整的自动化评测套件。基于四元组框架编写测试任务，结合确定性代码评分器（Code Graders）与大模型裁判（LLM-as-Judge），开展多轮稳定性统计（pass@k 与 passk）及系统性错误归因分析。
  • 课程项目：设计、构建与严格评测：从问题定义与基线建立（Proposal）、原型搭建（Midpoint Prototype）到完整消融实验与失败模式分析（Final Report & Demo）的全周期工程指南。
  • 论文精读与复现扩展（Paper Video）：选择前沿 Agent 研究论文，深入剖析其系统架构与实验假设，并通过动手复现或微型扩展实验检验论文的核心主张。
  • 配套代码架构导读：详细解析 HW1 代码库（assignment1-harness）的模块边界、类型契约与模拟评测框架，以及第 05 讲配套 Notebook（lecture5-frameworks）中 DSPy、LangGraph 与 Temporal 的实现细节。
